Experience

  1. MOIA

    Product Manager I, Rider Experience · Contract, Remote

    Dec 2025 – Nov 2026

    • Tracked the rider journey from booking to repeat ride in QuickSight for a mobility-as-a-service app, adding a churn-risk model in Python that scored each rider's likelihood to leave from ride frequency, wait times, and unfilled requests; the scores pointed the team to unfilled requests as the single biggest retention leak
    • Built a churn-rate dashboard with Claude Code (HTML, SQL via MCP) that replaced six team spreadsheets with one source, giving each team its own view, such as churn by district or riders most likely to leave
    • Identified recently underserved riders (e.g., unfilled request, late pickup) via SQL for lifecycle marketing's recovery campaign, then set up automated apology emails with a ride credit within 24 hours; 18% of 48,000 targeted riders rebooked within 30 days versus 13% in the control group, about 2,400 additional riders rebooked
    • Worked on a redesign of the “no car available” screen to offer alternatives instead, using Claude Code with the Canva MCP server for quick concept mockups and the Figma MCP server to turn final frames into code-ready components; riders accepted an alternative on 28% of 50,000 unfilled requests
    • Ran an eight-week 20% midday discount test with marketing to free up rush-hour cars, using SQL to target riders whose trip history showed flexible schedules; midday rides rose 9% versus the control group and unfilled rush-hour requests fell 6%, leading marketing to roll the offer out citywide
    • Wrote a searchable data dictionary for 60+ rider tables, each with plain-language definitions, a dependency map, and a tested SQL query, organized by journey stage (booking, ride, repeat); the ready-made queries unified metrics across team dashboards, replacing ad-hoc code that had caused reporting errors
    • Simplified the first-ride onboarding flow in Figma from six screens to four by saving payment up front, and added a first-ride credit; after launch, the share of new users who completed a first ride within seven days rose from 38% to 46%, tracked step by step in SQL
